# 终端皮肤

把 Harness 的 Web 界面渲染成等宽终端控制台：全站等宽字体、直角边框、无阴影、细窄方角滚动条、极淡的 CRT 扫描线，并提供绿色、琥珀色、黑白三套配色。左侧栏、主对话区、右侧边栏一起终端化。

## 功能

- 三套主题注册进 Harness 主题注册表：`Terminal green`、`Terminal amber`、`Terminal black`，可在「设置 → 外观」中切换，也可以在插件自己的设置页里一键切换。
- 配色由插件自己持有：即使你在设置里切到别的（浅色）主题，控制台外观也不会退回去；从设置里选回三套主题之一即可同步。
- `Ctrl+B` 收起或展开左侧栏（调用宿主已有的 `layout.toggleSidebar()`，不重建侧栏）。
- 覆盖四层：
  1. **主题 token**：14 个公开 alias token + `--dsw-specific-sidebar-fill`；
  2. **内部变量**：宿主样式表里真正绘制界面的变量（面板底色、按钮填充、气泡、输入区、markdown/代码、滚动条、圆角、字体族等）；
  3. **组件皮**：按 CSS Modules 的稳定局部名（`_bubble` / `_card` / `_primary` / `_sessionRow` / `_tab` / `_pill` / `_file`）加 1px 单线框、去圆角、强调色描边；
  4. **字形图标**：通过 `ThemeDefinition.icons` 把宿主图标精灵里的符号换成等宽字符（`+`、`>`、`v`、`^`、`...`、`[/]`、`!` ……），侧栏导航行直接隐藏图标、只留文字标签。
- 左侧栏按预览图的语汇重排：品牌行末尾是 `«` 收起按钮，新建会话是 `[+ 新会话 ]`，导航区以 `:: 导航` 开头、每行「字符图标 + 文字」，工作区分区标头是 `:: 工作区`，会话行用 `•`（当前）/`·`（其他）加右侧时间。
- 顶部条在标题前加 `~/` 路径前缀，标题行下沿是一条 1px 分隔线，状态图标（创造模式、后台任务）同样换成字符。
- 右侧边栏（工具面板、卡片行、标签）按同一套文字界面语汇重做：标签页显示成 `[ 开始 ]`，空面板顶部有 `:: 工具` 分区标头，每个入口是一行带 1px 边框的 `> 名称 / 说明 / 快捷键`，罗盘大图标与首屏插图隐藏，<kbd> 快捷键做成方角键帽。
- 配色会自动接管：插件首次生效时把主题偏好设为 `terminal-green`（此后尊重你在设置里的选择），字形图标只在终端主题处于选中状态时随主题生效。
- 输入框左侧是 `>` 提示符；对话区左边缘是 `you` / `dsh` 行首标签，像一份日志流。
- 对话区正文按预览图重新配色：正文 13px/20px，段落与表格沿用浅灰绿 `#c9d4c7`，加粗更亮，`##` 标题前缀是 `:: `、三级标题是 `# `，链接青色、引用左侧一条竖线、行内代码与代码块统一成深色面板 + 1px 边框。
- 工具栏与思考过程分层着色：工具调用行整行压暗、图标青色、失败状态转红；思考块用最淡的一档灰，避免和正文抢注意力。
- 三栏之间用 1px 竖线分隔：左侧栏右边框 + 右侧栏左边框，面板之间不再靠底色区分。
- 收起/展开侧栏的动画做了性能收紧（宿主用 `transition: all` 0.18s 动画侧栏宽度）：扫描线遮罩提升为独立合成层、`centerCol`/`rightbarCol` 加布局包含、`letter-spacing` 从通配规则移到 `body`、侧栏过渡缩到 0.13s、离屏消息行 `content-visibility: auto`。软件渲染下实测由 55fps/每 600ms 掉帧 6–7 帧提升到 59–60fps/掉帧 0–2 帧。
- 左上角品牌区换成文字标：鲸鱼图形隐藏，改为 `▚ deepseek-harness v0.7.0`（`▚` 用强调色、版本号用暗色）；版本号由 `VERSION` 常量写入 `--dsl-term-version`，改一处即同步。收起成 56px 轨道时自动只留 `▚` 标记，`:: 导航` / `:: 工作区` 这类小节标签也一并隐藏。
- 标签页（对话 / 轨迹 / 上下文…）的悬停反馈改成「只变色 + 一条淡下划线」，不再有比标签栏更高的填充块；当前页的下划线用强调色（宿主默认是蓝色，与配色冲突）。
- 开关控件改写成终端旋钮：深色轨道 + 1px 描边 + 固顶方块滑块（关＝灰、开＝强调色、悬停边框提亮）；卡片内部的分区层（head/end/link/body）不再各自描边，一张卡片只有一层外框。
- 刷新等图标也走字形表（`↻`），避免在中文等宽字体下退化成句号。
- 左侧栏收起成图标轨道时，新建会话按钮保留 `+` 字形（不再被隐藏），标签两侧的方括号只在展开态出现。
- 底部状态行借 `conversation.composer.dock` 空位挂载：`NORMAL | theme:<配色> | 时分`，悬停可见快捷键提示。
- 左下角账号行改成终端「登录态」：头像去色后与主题强调色做正片叠底，成为单色照片（绿/琥珀/黑白随配色变），名字前加 `@`，名字后接 `● Online`，两处都用当前强调色。收起成图标轨道时这些装饰自动让位，只留头像。
- 对话区左侧留白改成「时间 + 说话人」两行：第一行是从会话事件流里取的 `HH:MM:SS`（精确到秒，取 `event.time`），第二行是 `you` / `dsh`（助手一行用强调色）。时间由 `TerminalStatusBar` 里的一段 effect 从 `ctx.sessions.binding(sessionId).eventSource` 读取，按 `user/message`、`assistant/message` 的时间顺序分配给对应行；工具/思考行沿用当前轮的时间。开关在「设置 → 内置插件 → 终端皮肤 → 时间与对话者」，关闭后写 `dsh-terminal-skin:gutter=off` 并通过根属性 `data-dsh-terminal-gutter` 让留白与标记一起撤掉。
- 左下角头像提供「单色 / 原色」开关（`设置 → 内置插件 → 终端皮肤`）：单色是默认值，去色后与强调色做正片叠底；原色保留社交头像本身的颜色，切换写入 `dsh-terminal-skin:avatar`（`mono` / `color`），并通过根属性 `data-dsh-terminal-avatar` 即时生效。
- 账号行上方新增余额块（插槽 `sidebar.footer.action`，收起时整块隐藏）：两行分隔线之间是 `账户余额 / 今日消耗 / 上次对话 / 当前时段`。数据来自宿主自己的账户 RPC（`POST /api/account/getBalance`，body 形如 `{type:'client-request', rpcId, method:'account/getBalance', payload:{args:{client:{version,locale,timezoneOffsetSeconds}}}}`），余额每分钟取一次；另外监听聊天区变化，DOM 静止 2.5 秒且消息条数变化即视为「一轮结束」，立刻再取一次，用两次余额的差值累计今日消耗并记下上次对话消耗。台账存在 `localStorage` 的 `dsh-terminal-skin:ledger`（按北京日期分档，跨日重置）；峰谷按官方错峰规则：北京时间 **09:00–12:00、14:00–18:00 为峰时**，其余为谷时，并显示距下一次切换的时长。`峰时` / `谷时` 用主题强调色做底色、深色文字（终端反显块），换配色时底色跟着变。余额块可在「设置 → 内置插件 → 终端皮肤」里关闭（`dsh-terminal-skin:account`），关闭后不再请求余额接口。
- 余额块的已知边界：只做客户端观测；「上次对话」= 从你发出这条消息到这一轮回答结束的全部消耗（中途的每次采样都累加进同一个数，只有你发下一条消息才清零重开），所以同一轮内多次模型调用会合并成一个总数；充值（余额变大）不计入消耗；台账按 origin 存，换端口/换 profile 会从零开始；跨过北京时间零点「今日消耗」归零。
- 对比度：三套配色的正文、次级文字、分隔线整体提亮一档；另外提供「高对比度模式」，把正文再提到接近纯白、分隔线与气泡边线一并提亮。开关在「设置 → 内置插件 → 终端皮肤」，也可用 `window.__dshTerminalSkin.setContrast('high' | 'standard')` 切换；选择存进 `localStorage`（`dsh-terminal-skin:contrast`），重启窗口后保留。
- 配色切换也搬进了同一页：`绿色 / 琥珀 / 纯黑` 三个方角按钮，点一下即时换色并写进 `localStorage`（`dsh-terminal-skin:palette`）。原先的 `Ctrl+Alt+T` 全局快捷键已移除，避免和其他程序的热键冲突；插件现在只保留 `Ctrl+B` 一个快捷键。

## 使用

1. 安装并启用本插件，刷新/重启窗口（桌面版可按 `Ctrl+Shift+R` 重载页面）。
2. 在「设置 → 外观」选择三套终端主题之一，或进「设置 → 内置插件 → 终端皮肤」点 `绿色 / 琥珀 / 纯黑` 一键切换。
3. 按 `Ctrl+B` 收起侧栏。
4. 需要更强可读性时，在同一页打开「高对比度模式」。
5. 脚本里可用 `window.__dshTerminalSkin.paint('amber')` 直接切配色。

## 已知限制

- 只提供深色配色：终端皮肤与浅色界面冲突，因此三套主题都是深色。
- 字体族与组件皮通过一层受控样式覆盖（`html[data-dsh-terminal]` 作用域）；宿主组件的构建哈希会变，但局部名稳定，因此用子串选择器。极端重构下组件皮可能部分失效，颜色与主题不受影响。
- 字形图标只在「三套终端主题之一处于选中状态」时生效（图标随主题走）。从设置里选回内置主题时，插件会尽力把配色主题重新选中。
- 图标替换覆盖常用符号（导航、按钮、工具条）；宿主新增的图标会保持原样。
- 卸载插件会移除样式层与主题注册，界面恢复原样。
